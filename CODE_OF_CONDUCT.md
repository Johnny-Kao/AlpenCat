# Code of Conduct

AlpenCat follows the Contributor Covenant, version 2.1, as the behavioral
baseline for project participation:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Project discussions should remain technical, specific, and evidence-based.
Disagreement about architecture, benchmarks, APIs, or implementation choices is
expected; personal attacks, harassment, discrimination, and intimidation are
not acceptable.

For conduct concerns, contact the repository maintainer privately rather than
opening a public issue containing sensitive personal details.
